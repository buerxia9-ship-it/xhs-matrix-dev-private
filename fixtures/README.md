# Synthetic data boundary

It contains no production rows. Prisma schema and the effective SQL are retained together because runtime patches may extend storage behavior.
The fixture creator generates invented IDs, a generic persona, test pages and a draft; no platform account or model-provider record is created.
All fixture prose is explicitly synthetic and is not an account knowledge source.
Original product images, screenshots, donation QR codes, packaging registries and customer evidence are excluded.
The existing policy regression strings test prohibited and permitted language; their numeric or brand tokens are not current product claims.
